# Deprecated code names its replacement and removal owner

## Rule

Deprecated internal code requires owner, replacement, and remove-by metadata.

## Applies to

- `src/**/*.{ts,tsx,py}`
- `tests/**/*.{ts,tsx,py}`

## Runtime checks

- Kind: `validator`
- Severity: `warning`
- Scope: `file`
- Facts: `annotations`
