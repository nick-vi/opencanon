# Comments do not preserve stale compatibility intent

Convention id: `no-stale-intent-comments`.

## Rule

Comment describes stale compatibility intent.

## Applies to

- `src/**/*.{ts,tsx,py}`
- `tests/**/*.{ts,tsx,py}`

## Runtime checks

- Kind: `validator`
- Severity: `warning`
- Scope: `file`
- Facts: `comments`
